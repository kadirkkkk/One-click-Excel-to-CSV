# One-click-Excel-to-CSV
Right click excel file select convert to convert from xlsx to csv, xlsx to tab deliminated

How to use:
Configure: Open config.json and set your pageName (e.g., "Sheet1"), extension (e.g., ".csv"), and delimiter (e.g., "\t" for tab or ";" for semicolon).

Install: Right-click Install.bat -> Run as Administrator.

Run: Right-click any .xlsx or .xlsm file in Explorer and select "Excel to Tab delimited".

Result: A new file will appear in the same folder, and a summary box will pop up.
